# 🚀 QR-Generator-Pro - Advanced QR Code Generator

QR-Generator-Pro é uma ferramenta em Python para geração de QR Codes personalizados com suporte a:

- 🎨 Cores personalizadas
- 🌈 Gradiente de cores
- 🖼️ Logo central
- ⚡ Interface simples via terminal
- 🧩 Baseado em `qrcode` + `Pillow`

---

## 📦 Instalação

```bash
pip install qrcode[pil] pillow colorama
```

## ▶️ Como usar

```bash
python main.py
```

## ✨ Funcionalidades

###🔹 QR Code básico

Gera QR Code a partir de qualquer link ou texto.

### 🎨 Personalização de cores

Escolha cor do QR e do fundo.

### 🌈 Gradiente

Aplica um efeito visual moderno no QR Code.

### 🖼️ Logo no centro

Adicione sua marca ou imagem no meio do QR Code.
